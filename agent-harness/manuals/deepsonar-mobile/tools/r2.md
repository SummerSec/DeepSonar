# radare2 (r2)

> Agent 面向工具说明书。内部实现依赖不在此列。路径约定：镜像内 `/opt/deepsonar/manuals/`。

## 使用场景

native .so 交互/脚本化分析。

## 选型依据

只看 ELF 头用 readelf 足够。

## 前置条件

.so 文件。

## 调用方式

`r2 -c "ii; iz" -q lib.so`

最小示例：

```bash
r2 -v | head
```

## 输出解释

符号/字符串；静态观察。

## 失败处理

| 类别 | 表现 | 处理 |
| --- | --- | --- |
| 正常无结果 | 无信息 | 记录查询条件与空结果；不要升级为 needs_human |
| 可修正错误 | 非 ELF | 修正参数/路径后重试 |
| 可重试失败 | 无 | 有限次重试；仍失败则记 inconclusive |
| 缺少运行条件 | 无 r2 | 明确缺项；提交 needs_human / inconclusive，禁止编造 |

## 组合流程

readelf → r2 → frida。

## 证据留存

命令与关键输出。

## 版本与限制

mobile 钉选。
