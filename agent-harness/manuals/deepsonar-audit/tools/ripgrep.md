# ripgrep (rg)

> Agent 面向工具说明书。内部实现依赖不在此列。路径约定：镜像内 `/opt/deepsonar/manuals/`。

## 使用场景

在代码树中按正则快速检索符号、字符串、API 用法。

## 选型依据

不要对巨型二进制当文本硬扫（先 file）；结构化 APK 查询优先 droidasc；不要替代语义审计结论。

## 前置条件

目标目录可读。

## 调用方式

入口：`rg`。常用：`-n`、`-g`、`-F`、`--json`。

最小示例：

```bash
rg -n "memcpy\(" -g "*.c" . | head
```

## 输出解释

匹配行；无匹配退出码 1（正常无结果）。匹配只证明文本出现，不证明可达/可利用。

## 失败处理

| 类别 | 表现 | 处理 |
| --- | --- | --- |
| 正常无结果 | 退出码 1 无匹配 | 记录查询条件与空结果；不要升级为 needs_human |
| 可修正错误 | glob/正则错误 | 修正参数/路径后重试 |
| 可重试失败 | 极少 | 有限次重试；仍失败则记 inconclusive |
| 缺少运行条件 | 目录不存在 | 明确缺项；提交 needs_human / inconclusive，禁止编造 |

## 组合流程

定位后用编辑器/clang/jadx 精读；与 git grep 二选一即可。

## 证据留存

保存模式、路径过滤、命中摘录与文件修订。

## 版本与限制

apt ripgrep；大仓库注意输出裁剪。
