# d8

> Agent 面向工具说明书。内部实现依赖不在此列。路径约定：镜像内 `/opt/deepsonar/manuals/`。

## 使用场景

V8 shell 复现 JS 崩溃/行为。

## 选型依据

页面 XSS 用 chrome-test CDP。

## 前置条件

chrome-fuzz。

## 调用方式

`/opt/deepsonar/bin/d8 script.js`

最小示例：

```bash
/opt/deepsonar/bin/d8 -e "print(1+1)"
```

## 输出解释

打印/崩溃栈。

## 失败处理

| 类别 | 表现 | 处理 |
| --- | --- | --- |
| 正常无结果 | 无输出 | 记录查询条件与空结果；不要升级为 needs_human |
| 可修正错误 | 脚本错误 | 修正参数/路径后重试 |
| 可重试失败 | 无 | 有限次重试；仍失败则记 inconclusive |
| 缺少运行条件 | 无 d8 | 明确缺项；提交 needs_human / inconclusive，禁止编造 |

## 组合流程

最小化用例 → 证据包。

## 证据留存

脚本、参数、stderr。

## 版本与限制

钉选 V8。
