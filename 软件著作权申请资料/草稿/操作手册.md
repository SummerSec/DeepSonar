## 二、说明

深流循迹多智能体任务编排系统（DeepSonar）V1.0 是在浏览器里使用的工作台。安全或研发负责人把一次审计、分析或修补目标写成任务，系统在隔离环境里安排探索、分析、复核、测试等角色分头做事，过程画在一张图上，经过核对的发现再整理成可以交给别人的报告。

打开控制台后，先进入运行态势，再进项目空间。一个项目长期保存同一审查对象的配置和历史记录；每一次具体目标是一条任务。任务开跑之后，可以在任务详情里看图、看事实、看发现，也可以回复系统提出的人工请求。管理员另外准备账号、模型凭据和运行环境，任务填写处不能指定运行环境地址。

本手册按用户实际打开的页面书写。截图位置已留出，插入时请使用对应页面的真实画面。

## 三、功能特点

登录页用于进入控制台。新部署、还没有人用过时，先创建首位管理员；之后用账号密码进入，自动化场景也可以粘贴访问令牌。

运行态势把当前有多少项目、任务、运行和发现放在一张总览里，并把等待人工、运行失败、高风险尚未核对的条目单独列出来，方便上班先处理要紧的事。

项目空间用来新建、查找、改名和归档工作空间。任务工作台在选定项目里下达普通任务或组合任务，普通任务写标题和内容，组合任务只能从本项目已有发现里挑选种子，不能把范围扩到别的资产。任务可以马上开始，也可以指定北京时间再开始，并决定这次是否允许出网。

任务详情里有画布、事实、发现、运行和报告几个页签。画布只能看、不能拖。运行中可以给决策中枢或某一次运行补说明、传附件。发现列表把技术核对状态和人工处置状态分开，人可以评论、改处置，但不能把一条发现直接标成“已确认”。调度队列用来跨项目取消卡住的运行或把失败、超时、孤儿运行重新排队。项目报告按任务下载总报告和已确认发现的独立报告。项目账本按周期核对调用次数和用量。Agent 管理、Agent 市场、镜像市场、凭据和配置中心供管理员事先准备角色和环境。项目数据页导入导出本项目的数据包。

## 五、登录与首次管理员

浏览器打开控制台地址后会出现登录页。还没登录就访问其他地址，也会被带到这里。页面上方是 DeepSonar 标志，下面可以在「账号登录」「创建管理员」「API Token」之间切换。

第一次部署、系统提示还没有用户时，切到创建管理员，填写用户名和至少八位密码，显示名可空，提交后进入控制台。以后日常使用切回账号登录，填用户名和密码即可。给脚本或外部系统用时，切到 API Token，把令牌粘进去。用户名和密码为空会拦下；登录失败时错误文字出现在表单下方，人还留在登录页。已经登录再打开登录页，会直接进到原来要去的页面，默认是运行态势。

## 六、运行态势

登录成功后默认停在运行态势，也可以随时点左侧「态势」。页顶有项目、任务、运行、发现四张数量卡片，下面是需要人处理的事项：等待人工、运行异常、高风险还没核对完的发现，再往下是分布和近七日趋势。

数量大约每五秒刷新一次。点关注列表里的某一条，会跳到对应任务或项目风险。如果还没有任何项目，页面会提示先创建项目，按钮会带到项目空间。调度服务连不上时，页面写明调度器暂时不可达，并请确认服务是否已在本机启动；恢复后会自动重新拉数，不必手动刷新。

【截图预留：请在此处插入「运行态势」首页截图。】

## 七、项目空间

左侧点「项目」，或从态势空状态里的「创建项目」进来。页顶有「新建项目」和「从一句目标开始」。新建时填写名称和说明，名称不能空。从一句目标开始则是先写下本次要做什么，再落到新建项目。列表可用关键字搜索，并可只看活跃或已归档的项目。卡片上能改名称、说明，工作结束后可以归档。归档后的项目不能再下达新任务。操作结果会在页顶短暂提示。新建成功的项目出现在活跃列表，点进去就是任务工作台。

【截图预留：请在此处插入「项目空间」列表或新建项目表单截图。】

## 八、任务工作台

进入某个活跃项目后，默认就是任务工作台，左侧也可以再点一次「任务工作台」。右上角「下达任务」打开表单。普通任务填写标题和内容。组合任务要从本项目已有发现里勾选一到八条作为种子，只围绕这些发现继续核对或补证。出网可以继承项目设置，也可以本次允许或禁止。开始时间可以立刻开始，也可以指定北京时间；指定的时间如果已经过去，页面会提醒。已归档项目看不到下达按钮。提交成功后打开该任务详情。列表可用「正在推进」「已有发现」「已归档」过滤。列表是否显示在推进，看的是还有没有进行中的运行，而不是某一次运行已经成功。

【截图预留：请在此处插入「任务工作台」列表或下达任务表单截图。】

## 九、任务详情、过程画布与人工介入

在任务列表点一条，或从态势、调度队列的链接进来。上方是任务标题、暂停或继续、返回列表。中间有画布、事实、发现、运行、报告几个页签。画布展示事实和下一步意图怎么接上，节点位置不能拖。事实和发现页签可以打开某一条看正文和核对状态。运行页签列出各次隔离执行，需要时能打开会话记录。

系统在等你说话时，页上会出现人工介入条。选好要回复的对象，写一到八千字，需要的话附上文件再发送。附件必须全部传完才会发出这一条。已经结束或并没有在跑的对象收不到定向消息。发送后可以看到计划中、已注入、已确认等状态；只有系统记下对方回执后，界面才显示已确认。也可以忽略该项，让任务继续。失败、超时或孤儿运行，用页面上的恢复把它重新排进队列。人不能在这里把发现直接标成已确认。报告生成完成后，报告页签提供下载。

## 十、项目风险与跨项目发现

项目内点「项目风险」，看的是这个项目全部任务里的发现，不是单张画布。要在多个项目之间查找，用命令菜单里的「跨项目发现」。页上有搜索框，以及严重程度、核对状态、处置状态等筛选。表格里每一行同时标出技术核对和人工处置。

点开一条可以看到详情、证据和评论。处置按事务跟踪的方式改，也可以留言让分析继续。核对状态由系统根据核对结果改，页面没有“直接确认”的按钮。需要把若干条已有发现合在一起往下做时，最多选八条本项目允许的发现，下达组合任务，成功后进入新的任务详情。列表很长时会提示还没有加载完全部条目。筛选后表格和计数一起变。

【截图预留：请在此处插入「项目风险」列表或发现详情截图。】

## 十一、调度队列

命令菜单里的「跨项目运行」打开调度队列，用来查找卡住或失败的执行。可以用状态、项目等条件过滤，下面有计数条。表格列出类型、状态、所属任务和时间。点开一条能看到项目、任务和错误说明。仍在排队或正在跑的可以取消；等待人工、失败、超时、孤儿的可以恢复，恢复后重新进入排队。取消和恢复前会弹出确认。完成后状态会更新，也可以跳回对应任务。

【截图预留：请在此处插入「调度队列」列表或运行详情截图。】

## 十二、项目报告

项目内点「项目报告」。页上统计有多少任务、多少份总报告版本。列表按任务分组，每组里是各版本总报告和已经确认的发现的独立报告。任务详情的报告页签只看当前这一条任务。

展开某个任务，能看到版本号和生成时间。生成成功的版本可以下载 Markdown，浏览器会保存文件。仍在生成的版本只显示状态，不能下。报告是发现被确认或任务收束之后由系统写出的，不能在这一页手工造一份。还没有报告时，按提示等待，或回去看任务是否已经收束。

【截图预留：请在此处插入「项目报告」按任务分组的列表截图。】

## 十三、项目账本

项目内点「项目账本」。运行态势上也有全局用量。这里按周或其他预设周期统计调用次数、输入量、输出量和缓存命中，也可以自定义起止日期。自定义时开始日期不能晚于结束日期，日期没选齐会提示先选齐。数字可以按日、按任务、按所用智能服务展开。没有用量时显示空状态。账本区块可以折叠，以免挡住别的内容。

【截图预留：请在此处插入「项目账本」用量统计截图。】

## 十四、Agent 管理与 Agent 市场

左侧能力区有「Agent」和「Agent 市场」，需要相应权限才看得到。Agent 管理列出平台有哪些角色、默认怎么跑。项目里只决定启用哪些角色，必要时做覆盖。Agent 市场用来安装已经受管理的角色配置包，也可以上传配置包；安装只写入角色和运行配置，不会把长期密钥带进来。没有写入权限时会提示不能安装，配置包过大也会被拒绝。装好后角色出现在 Agent 管理里，失败时页上给出原因。再到该项目的项目策略里勾选本项目要用的角色。

【截图预留：请在此处插入「Agent 管理」或「Agent 市场」截图。】

## 十五、镜像市场与项目镜像

左侧「镜像」是全平台镜像市场；项目里的「项目镜像」只管理本项目启用了哪些。系统有默认底座。专项环境和第三方环境要先登记、准入，再在项目里启用。任务表单里没有镜像地址栏。

市场里可以搜索、按处理器平台筛选，也可以同步官方目录、拉取、导出清单。第三方先进入隔离区，检测通过后由有权限的人授权采用；检测未通过不能采用。手工登记必须提供带摘要的不可变引用。项目页上启用或固定本项目允许使用的专项或第三方环境。未绑定专项环境的角色仍走系统底座。同步、拉取、登记的结果都在页上提示。

【截图预留：请在此处插入「镜像市场」或「项目运行镜像」截图。】

## 十六、安全与访问、凭据和配置中心

左侧平台区有「安全与访问」「凭据」「配置中心」；项目内是「项目策略」。没有权限的入口不会出现，或保存时被拒绝。

安全与访问里维护用户角色，也可以给自动化签发 Token。凭据里新增或更新上游智能服务账号，保存前可以测连通；界面只显示有没有保存过，不显示明文密钥，完整命令行配置也不会在管理界面里摊开。配置中心看全局调度和护栏。项目策略只改本项目相对全局的差异，例如启用哪些角色；改完只影响这之后在本项目新建的任务。项目数据包仍到项目数据页处理。保存成功有提示，测试连通会返回结果。

【截图预留：请在此处插入「安全与访问」「凭据」或「项目策略」截图。】

## 十七、项目数据导入导出

项目内点「项目数据」。平台级配置不在这一页，到配置中心处理。导出时选择要带走的模块或预设，开始后等待生成数据包再下载。导入时选本地数据包，确认范围后开始，等后台结束再按提示检查项目里有没有相应任务或配置。导入前系统会清掉不安全内容。失败时页面说明原因，不会悄悄覆盖。导出完成即可下载文件。

## 十八、日常使用顺序

第一次部署，在登录页创建首位管理员，或用已有账号、访问令牌进入。到项目空间建一个项目，写好名称和说明。若角色、凭据、运行环境还没准备，先到 Agent 管理、凭据和镜像市场处理。回到该项目的任务工作台，写标题和目标，选择马上开始或预约时间后下达。打开任务详情看图、看事实和发现；系统来问时再回复。在项目风险里跟进发现，必要时用已有发现开组合任务。任务收束后到项目报告下载总报告和已确认发现的报告，并在项目账本里核对这次用了多少调用。

## 十九、常见问题解答

问题：登录后看不到项目或任务，是不是坏了？
解决方法：先看运行态势有没有写调度器暂时不可达。服务正常但列表仍空，说明还没有项目，到项目空间新建后再下达任务。

问题：任务里某一次运行已经成功，为什么还显示在推进？
解决方法：看的是还有没有进行中的运行。决策中枢只要还在派后面的工作，任务就会继续显示在推进。

问题：能不能在发现详情里直接标成已确认？
解决方法：不能。是否确认由系统根据核对过的事实决定。人可以评论、改处置、请人补证，或把需要人判断的条目标成待人工。

问题：下达任务时为什么选不了运行环境？
解决方法：运行环境由管理员在镜像市场登记，并在项目镜像页启用。任务只填目标和这次是否出网，避免任务内容指定不可信环境。

问题：组合任务和普通任务有什么不同？
解决方法：普通任务用标题和内容描述新目标。组合任务必须从本项目已有发现里选一到八条当种子，只围绕这些发现继续核对或补证，不能扩大范围。

问题：凭据页为什么看不到完整密钥？
解决方法：管理界面只显示有没有保存过。完整密钥只在真正执行时放进隔离环境，避免在控制台泄露。

## 二十、术语表

| 术语 | 解释 |
| --- | --- |
| 项目 | 长期工作空间，保存审查对象范围、角色配置和历史记录。 |
| 任务 | 一次具体目标，对应一张过程图。 |
| 画布 | 展示本次任务里事实、意图、发现如何衔接的图，只能看，不能由执行方改位置。 |
| 决策中枢 | 阅读当前图之后决定下一步派谁、做什么，由事情到来时触发，不靠人定时去点刷新。 |
| 事实 | 工作角色提交的一条记录，后续核对应采信这些记录。 |
| 发现 | 一条需要跟踪的问题或结论，带严重程度、核对状态和人工处置状态。 |
| 运行 | 一次隔离环境中的实际执行，有排队、运行、成功、失败、超时、取消、孤儿等状态。 |
| 验证 | 系统根据事实判断发现是否成立，不再去读提出该发现的角色自己的结论。 |
| 组合任务 | 以本项目已有发现为种子继续深挖的任务，不得扩大范围。 |
| 镜像 | 智能体实际干活时用的软件环境。只有登记过并在项目里启用的才会被用到。 |
