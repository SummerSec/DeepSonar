# 业务理解

- 软件名称：深流循迹多智能体任务编排系统
- 产品定位：面向软件审计与工程分析场景的本地控制台：人在浏览器里建立项目与任务，调度器在隔离沙箱中运行多角色智能体，把探索、分析、复核、验证和报告收敛到同一张任务画布上。产品中文名称为深流循迹，英文名称为 DeepSonar。
- 面向领域 / 行业：人工智能应用软件（智能体任务编排）与信息安全审计
- 核心价值：把“人下达目标、智能体只提案、系统负责落地和记账”做成一条可见闭环：项目是长期工作空间，任务是一张过程画布，发现必须经过验证才能成为可交付报告，执行始终发生在一次性沙箱中。
- 证据文件：`业务理解证据.md`

## 目标用户

- 安全审计与代码审查负责人，需要把审计目标下达给多角色智能体并跟踪发现是否被验证
- 研发或工程效能团队，需要把探索、分析、测试、修补等步骤编排成可回溯的任务闭环
- 平台管理员，负责账号权限、模型凭据、角色配置、运行镜像准入与项目数据导入导出

## 主要业务功能

- 登录与访问控制
- 运行态势总览
- 项目空间管理
- 任务下达与工作台
- 任务过程画布与人工介入
- 发现与风险处置
- 调度队列与运行恢复
- 任务与 Finding 报告
- 项目账本与用量
- 角色、市场与运行镜像治理
- 平台凭据与配置中心
- 项目数据导入导出

## 功能说明

- 登录与访问控制：控制台支持账号密码登录、首次创建管理员，以及用 API Token 进入。角色分为管理员、操作员、只读人员。未登录访问受保护页面会回到登录页。
- 运行态势总览：首页「运行态势」汇总项目、任务、运行和发现数量，列出需要人工介入、运行异常和高风险待验证事项，并可跳转到对应项目或任务。
- 项目空间管理：「项目空间」用于新建、搜索、编辑、归档项目。一个项目承载代码边界、Agent 配置和长期证据；具体目标作为独立任务进入同一闭环。
- 任务下达与工作台：进入项目后的「任务工作台」可下达普通任务或组合任务。普通任务填写标题与内容即可启动；组合任务只能选择本项目已有发现作为种子，不得扩大资产范围。可立即开始或预约开始时间，并可覆盖本任务是否允许出网。
- 任务过程画布与人工介入：打开具体任务后可查看过程画布、事实、发现、运行和报告。画布只读展示事实与意图关系。运行中可向 Hub 或指定运行发送人工消息和附件；遇到等待人工、失败或孤儿运行时可回复、忽略或恢复。
- 发现与风险处置：项目内「项目风险」列出本项目全部任务的发现，可按严重程度、验证状态和处置状态筛选。处置类似事务跟踪：打开、评论、改变处置。全局「发现」用于跨项目检索。达到验证门槛的发现由系统安排验证，人工不能直接把发现标成已确认。
- 调度队列与运行恢复：跨项目「调度队列」列出各次沙箱运行状态，可筛选、打开详情、取消进行中的运行，或恢复失败、超时、孤儿和等待人工的运行。
- 任务与 Finding 报告：画布收敛后生成版本化任务总报告；发现被确认后生成独立 Finding 报告。「项目报告」按任务分组查看并下载 Markdown。
- 项目账本与用量：「项目账本」按周期统计模型调用次数、输入输出量和缓存命中，可按项目或任务查看，便于核对一次审计消耗了多少额度。
- 角色、市场与运行镜像治理：「Agent 管理」定义角色能力与默认运行配置；「Agent 市场」安装受治理的角色配置包；「镜像市场」管理可信运行环境。第三方镜像必须先隔离扫描、管理员批准、项目启用后才能真正执行，任务表单不能指定镜像引用。
- 平台凭据与配置中心：「安全与访问」管理用户和 API Token；「凭据」绑定上游模型密钥且界面不回显明文；「配置中心」维护运行时护栏与调度纪律。项目「项目策略」只覆盖本项目相对全局的差异。
- 项目数据导入导出：「项目数据」可导出或导入本项目的 .deepsonarpack 数据包，用于迁移配置与任务历史；导入前系统会清理不安全内容。

## 典型操作流程

1. 首次部署后在登录页创建首位管理员，或使用已有账号、API Token 进入控制台
2. 在项目空间新建项目，确认项目名称、说明和默认出网策略
3. 按需在 Agent 管理、凭据、镜像市场中准备角色、模型和可信运行环境
4. 进入该项目的任务工作台，填写标题与目标内容，选择立即开始或预约时间后下达任务
5. 打开任务详情查看过程画布、事实、发现和运行状态；必要时回复人工介入或调整任务
6. 在项目风险中查看发现，按验证状态和处置状态跟进，必要时围绕已有发现下达组合任务
7. 任务收敛后在项目报告中下载任务总报告和已确认发现的独立报告，并在项目账本核对用量

## 操作手册页面/流程模块

1. 登录与首次管理员：浏览器打开控制台地址后进入登录页；访问其他页面未登录时也会被带到这里。
   - 使用场景：第一次打开控制台，或会话过期后重新进入。管理员尚未创建时，需要先建账号才能继续。
   - 操作要点：若页面提示尚无用户，切换到创建管理员，填写用户名和至少 8 位密码，可选填写显示名后提交。；已有账号时，切换到账号登录，填写用户名和密码后提交。；自动化访问可切换到 API Token，粘贴令牌后进入。；登录成功后进入原先要访问的页面，默认是运行态势。
2. 运行态势：登录后默认进入；也可在左侧导航点击「态势」。
   - 使用场景：每天开始工作或巡检时先看这里，确认有没有等待人工、运行失败或高风险未验证的发现。
   - 操作要点：查看顶部数量卡片，了解当前有多少项目、任务、进行中的运行和发现。；在关注列表中点击某一条，跳到对应任务或项目风险。；若提示还没有项目空间，点击「创建项目」去项目页新建。；调度器连不上时，按页面提示确认服务是否已启动，页面会在恢复后自动同步。
3. 项目空间：左侧导航「项目」，或态势页空状态中的「创建项目」。
   - 使用场景：开始一项新的审计对象、归档已经结束的工作空间，或按名称查找已有项目。
   - 操作要点：点击「新建项目」，填写名称和说明后提交。；也可点击「从一句目标开始」，先写一句目标再落到新建流程。；在搜索框输入关键字过滤项目；用筛选查看活跃或已归档项目。；需要更名或改说明时打开编辑；工作结束后可将项目归档。
4. 任务工作台：打开某个项目后默认进入任务页；也可在项目内左侧点「任务工作台」。
   - 使用场景：已经有项目之后，把本次审计或分析目标写成任务，选择立即开始或预约时间。
   - 操作要点：确认当前项目为活跃后点击「下达任务」。；普通任务填写标题和内容；组合任务从本项目已有发现中勾选 1 到 8 条作为种子。；选择继承项目出网、允许出网或禁止出网；选择立即开始或指定北京时间开始。；提交后进入该任务详情。可用筛选查看正在推进或已有发现的任务。
5. 任务详情、过程画布与人工介入：在任务工作台点击某条任务，或从态势、调度队列的链接进入。
   - 使用场景：任务已经下达后，跟踪画布上的事实和发现，查看某次运行的会话，或回复系统提出的人工请求。
   - 操作要点：默认查看过程画布，了解事实与后续意图如何衔接。画布节点不能拖动。；切换到事实或发现页签，打开某一条查看内容和验证状态。；切换到运行页签查看各次沙箱运行；需要时打开会话记录。；出现等待人工时，在介入条中选择对象，填写 1 到 8000 字说明，必要时附加文件后发送；也可忽略该项让任务继续。
6. 项目风险与跨项目发现：项目内点「项目风险」；跨项目检索用命令菜单或「跨项目发现」。
   - 使用场景：审计过程中核对某项目全部风险，或在多个项目之间检索同一类问题。
   - 操作要点：用筛选缩小到待验证、待人工或高严重程度条目。；点开一条查看详情、证据和评论。；按类似事务跟踪的方式调整处置，或留言触发继续分析。；需要组合已有发现时，选择最多 8 条合法发现，下达组合任务。
7. 调度队列：命令菜单中的「跨项目运行」，或直接打开调度队列页。
   - 使用场景：态势上出现运行异常，或需要按状态查找等待人工、失败、超时、孤儿的运行。
   - 操作要点：按状态筛选进行中、等待人工、失败、超时或孤儿。；点开一条查看所属项目、任务和错误信息。；对仍在排队或运行中的条目可取消。；对等待人工、失败、超时、孤儿的条目可恢复，使其重新进入排队。
8. 项目报告：项目内左侧「项目报告」。任务详情的报告页签也可查看当前任务的报告。
   - 使用场景：任务已经收敛，或某些发现已经确认，需要把书面结果交给其他人。
   - 操作要点：展开某个任务，查看总报告各版本和生成时间。；对已成功的版本点击 Markdown 下载。；在同一任务下查看已确认发现的独立报告并下载。；尚无报告时按页面提示等待生成或检查任务是否已收敛。
9. 项目账本：项目内左侧「项目账本」。运行态势页也有全局用量区域。
   - 使用场景：核对一次审计消耗了多少调用，或比较不同任务、不同模型的用量。
   - 操作要点：选择统计周期；自定义时填写开始和结束日期。；查看总量，再按任务或模型展开明细。；需要时折叠或展开账本区块。
10. Agent 管理与 Agent 市场：左侧能力区「Agent」和「Agent 市场」。需要相应读取或写入权限。
   - 使用场景：上线新的探索、分析、测试等角色，或把一套已审核的角色配置安装进平台，但不在这里粘贴长期密钥。
   - 操作要点：在 Agent 管理中查看或编辑角色能力与默认运行配置。；到 Agent 市场浏览官方或已登记模板，确认后安装。；也可上传 JSON 配置包；安装只写入角色和运行配置。；回到具体项目的项目策略，决定本项目启用哪些角色。
11. 镜像市场与项目镜像：左侧「镜像」进入全平台镜像市场；项目内「项目镜像」只管理本项目启用情况。
   - 使用场景：管理员同步或导入镜像目录，批准第三方镜像；项目负责人只启用本项目需要的专项或第三方镜像。任务表单不能填写镜像地址。
   - 操作要点：在镜像市场搜索或按 CPU 平台筛选。；需要时同步官方目录、拉取镜像或导出清单。；第三方镜像先导入隔离区，检测通过后由有权限的人授权采用。；到项目镜像页启用或固定本项目允许使用的专项/第三方镜像。
12. 安全与访问、凭据和配置中心：左侧平台区「安全与访问」「凭据」「配置中心」；项目内「项目策略」。
   - 使用场景：开通或停用用户、签发 API Token、绑定模型凭据、调整调度护栏；在某个项目里启用不同角色或规则。
   - 操作要点：在安全与访问中维护用户角色，或为自动化签发 Token。；在凭据中新增或更新上游模型账号，保存前可测试连通；界面只显示是否已保存，不显示明文密钥。；在配置中心查看或调整全局调度与护栏。；到项目策略中启用本项目角色，或覆盖部分运行配置。数据包仍在项目数据页处理。
13. 项目数据导入导出：项目内左侧「项目数据」。平台级配置包在配置中心处理，不在本页。
   - 使用场景：迁移项目、备份任务历史，或在另一套环境恢复同一项目的工作记录。
   - 操作要点：导出时选择要包含的模块或预设，开始导出，等待生成 .deepsonarpack 文件后下载。；导入时选择本地数据包，确认范围后开始导入。；等待后台任务结束，按结果提示检查项目内容。

## 申请表建议口径

- 开发目的：为软件审计与工程分析团队提供可收敛、可审计的多智能体任务编排控制台
- 软件的主要功能：本软件提供浏览器控制台，用于管理软件审计与工程分析任务。用户先登录并建立项目空间，再以自然语言下达任务。系统把每次任务做成一张过程画布，由决策中枢阅读当前事实后派发探索、分析、复核、测试、编码等角色。角色只提交事实和发现，是否验证、是否出报告由调度器决定。发现按严重程度进入验证生命周期，验证通过后生成独立报告，画布收敛后生成任务总报告。控制台同时提供跨项目发现检索、调度队列恢复、角色与镜像治理、模型凭据管理、项目用量账本和数据包导入导出。执行发生在一次性隔离沙箱中，长期密钥不进入工作区。
- 技术特点：Web 控制台加调度器闭环；智能体只提案、系统记账；隔离沙箱与不可变镜像摘要；事实优先的发现验证。
- 软件的技术特点选项：人工智能软件、信息安全软件、云计算软件
- 软件分类：应用软件
