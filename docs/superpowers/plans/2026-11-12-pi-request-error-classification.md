## 评审重点

1. 异常字符串不能伪造宿主错误身份或永久状态/恢复许可。
2. allowance/SDK/settlement 的失败阶段必须准确，未知阶段不得假定未执行。
3. 取消优先于嵌套 timeout/network，永久拒绝不能因伴随网络文本恢复。
4. 错误原因允许名单与长度上限必须先于序列化；未知值保持 unknown。
5. 已接受完成拒绝沿用私有宿主信号，不能被 SDK 同名错误冒充。
