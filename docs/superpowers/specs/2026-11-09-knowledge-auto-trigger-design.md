# 知识来源登记与历史预览：收敛设计

用户于2026-11-09确定本轮只保留成功来源登记、Barry 全局 Skill 既有源接入和历史补做预览，取代此前的自动执行方案。

- 成功且最新 Attempt 成功、冻结允许整理、无未结算效果的业务 Job，若有自身 Fact/Evidence，写一条有界系统审计记录；重复终态不重复登记。
- GET 历史预览分页显示当前资格、原因、登记记录及已有 work，执行项目读权限检查；无 POST、不写历史记录、不返回正文。
- 不建立来源表，不变更 schema、网关、预算或模型执行通道；旧自动 work 保留且不再自动启动后续阶段。
- 全局 Skill 已通过既有可信源同步接入；不自动回写 GitHub，不把导入的上游 Skill 当作新沉淀。

注意力成本与历史边界以 [ADR 0021](../../architecture/adr/0021-knowledge-source-preview.md) 为准。实际运行平台尚未因本 PR 自动升级，工程验证与部署分别报告。
