## 3. 七项决策

每项格式：选项 → 选定 → 后果。**设计文档建议**一栏只是 PR #816 作者的建议，未经批准。

### 决策 1：`requires_egress` / `requires_gateway` 是否拆字段

| 项 | 内容 |
| --- | --- |
| 选项 A | 拆成两个正交必填字段，缺省即拒绝注册（fail closed） |
| 选项 B | 保持单字段，把 om 判为不兼容断网 Job |
| 设计文档建议 | A（单字段会留下不可审计的静默跳过） |
| 选定 | ☐ A ☐ B |
| 后果 | 选 A：B 片必须改 `PiExtensionRegistration` 契约并重生成注册表。选 B：断网 Job 场景直接放弃 om，改动最小 |

依据：`packages/shared-types/src/pi-extensions.ts` 当前只有 `requires_egress`；`apps/scheduler/src/pi-extensions.ts` 在 `allowEgress=false` 时静默跳过该扩展。

### 决策 2：主动模式与 passive 的调用边界

| 项 | 内容 |
| --- | --- |
| 选项 A | 两种模式都经完整模型治理（预算、归因、白名单） |
| 选项 B | 拒绝接入 |
| 设计文档建议 | A；治理未落地不得以 passive 替代 |
| 选定 | ☐ A ☐ B |
| 后果 | passive 不是「零模型调用」保证：上游 `compaction-hook.ts` 可调用 `runObserver` |

### 决策 3：后台 worker 失败是否允许拖垮 Job

| 项 | 内容 |
| --- | --- |
| 选项 A | 接受 Job 失败（现状语义） |
| 选项 B | 必须降级，记忆失败不影响主会话 |
| 设计文档建议 | B |
| 选定 | ☐ A ☐ B |
| 后果 | 选 B 要改内核 RPC 事件处理：`packages/runtime-sandbox/src/runtime-adapters.ts` 目前对 `error` / `extension_error` 直接 `failRuntime`，属内核级改动，不是 om 自己能解决的 |

### 决策 4：显式有限总额下的保底契约

| 项 | 内容 |
| --- | --- |
| 选项 A | 显式预留（比例或绝对值），`0 < R ≤ N` |
| 选项 B | 可证明有效的后台隔离 |
| 选项 C | 不选契约：有限总额下不启用 om |
| 设计文档建议 | 默认不限且不预留；有限总额未选契约不得启用，不隐式补额度 |
| 选定 | ☐ A ☐ B ☐ C |
| 后果 | 评审给出的反例：`N=1` 且未配置预留时，后台可先消耗唯一额度，主会话随后被拒。选 A/B 必须同时填写 §4 的数值并补离线验收 |

### 决策 5：独立可信 workload 归因实现方式

| 项 | 内容 |
| --- | --- |
| 选项 A | 内核绑定的独立 token |
| 选项 B | 可信调用上下文 |
| 设计文档建议 | 待 D 片评审；拒绝自报 header，保留原结算 source、模型白名单与全出口治理 |
| 选定 | ☐ A ☐ B ☐ 延后到 D 片 |
| 后果 | 不解决则无法区分主会话与后台请求的额度归属；延后到 D 片意味着 D 不得启用 |

### 决策 6：压缩身份链与 om 的关系

| 项 | 内容 |
| --- | --- |
| 选项 A | 以 DeepSonar 身份为准，om 无法表达时降级为 `context.compaction_unknown` |
| 选项 B | 扩展新 policy 表达 om |
| 设计文档建议 | A（先诚实降级，有真实需求再扩契约） |
| 选定 | ☐ A ☐ B |
| 后果 | 选 B 要扩 `context.compacted` 的契约与消费方，工作量与回归面显著增加 |

### 决策 7：observer 是否允许独立模型

| 项 | 内容 |
| --- | --- |
| 选项 A | 只允许冻结模型（C 片不写 `model` 键） |
| 选项 B | 允许，但受白名单与额度约束（需 D 片单独评审） |
| 设计文档建议 | A |
| 选定 | ☐ A ☐ B |
| 后果 | `provider.anthropic` 与 `provider.openai` 都是 `enforce_frozen_model: true`（`domains/provider-adapter/catalog.ts`），选 B 必须同时扩白名单，否则后台请求必然 `GATEWAY_FROZEN_MODEL_MISMATCH`，再叠加 `extension_error → failRuntime` 就是整 Job 失败 |
