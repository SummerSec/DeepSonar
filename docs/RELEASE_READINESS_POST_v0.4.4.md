## 10. 建议关闭条件（本 Issue）

本单是**发布验收与文档缺口**汇集，不是产品功能：

1. 仓库内具备可复查的中文清单（本文），每项标明 **已核实（代码/CI）** 或 **延期（需实机）+ 影响**。
2. 不以「CI green」代替数据副本 upgrade / 生产部署验收。
3. 文档中的 schema 版本字面量与 `SCHEMA_VERSION` 一致（v52）。
4. 实机项可在发版 checklist 中继续跟踪；关闭本单**不**等于下一版本已可对外宣布升级成功。

**发版门禁（产品规则，另跟踪）**：用户要求下一版本（如 v0.4.5）前清空开放 Issue；本清单中的 **延期（需实机）** 项应在打 tag 前完成或由负责人书面接受风险。
